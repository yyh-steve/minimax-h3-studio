运行配置

本地 H3 仅支持 MiniMax-H3、768P、单张参考图（reference）、每镜 4–15 秒。Base URL 示例：http://127.0.0.1:30010。建议并发 1、自动重试 0，先关闭 M3 看片。本地失败需人工处理，不会自动重新生成；保存设置不会转换已有分镜。
存在活动任务时，后端会拒绝切换 provider 或 Base URL；请先处理这些任务。
Key 保存在当前应用进程；需要重启后保留时请配置本机 .env。留空不改原值，保存成功后清空输入框。旧共享 Key 仅在 official 且独立 Key 未设置时使用；local 必须填写与本地服务一致的独立 H3 Key（至少 24 位无空白 ASCII 字符）。
